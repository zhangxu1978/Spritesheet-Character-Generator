### 环境踩坑（Windows）
1. **沙箱写保护**：bash 进程无法写 git 跟踪的 `CREDITS.csv`、`z_positions.csv`、`package-lock.json`（EPERM），但 dist/.cache/node_modules 可写、工具通道（Edit/Write）可写源码
2. 因此构建需绕过 regenerate：手动 `generateSources({writeMetadata:true,writeCredits:false})` 生成 dist 元数据 + 写 `.cache/lpc-source-inputs.sha256` fingerprint，然后 `npx vite build`（跳过 prebuild）成功
3. **遗留问题**：`scripts/zPositioning/z_positions.csv` 被误删重建为空文件，`.bak` 备份残留。恢复方法（用户环境执行）：
   ```
   git checkout -- scripts/zPositioning/z_positions.csv
   del scripts\zPositioning\z_positions.csv.bak
   ```
   或运行 `npm run validate-site-sources` 重新生成
4. `vite dev` 在此环境启动缓慢/无响应，改用 python http.server 服务 dist 预览

### 技术要点
- ItemWithVariants/ItemWithRecolors 中 `displayName === "Body Color"` 是逻辑判断，必须用原始 `meta.name`（翻译后判断会失效）
- zip.ts 导出只用 `anim.value`/`noExport`，汉化 label 不影响导出
- wordTranslate 会压缩中文词间空格（"浅 棕色"→"浅棕色"），括号内单词也能翻译
